## How it works

TestLink runs on each Mac from `qa/testlink/` (Docker). It starts with the UniShare project (prefix `US`), the
plan `Project 1 - Test Case Design`, build `UniShare main@b124314`, Rawa's suites and a login per member
(login = password = your name in lowercase; admin/admin).

Each tester writes their test basis and test cases as data in `qa/testlink/scripts/<name>_testdata.py`
(same format as `rawa_testdata.py`), loads it into TestLink and prints their PDFs:

```bash
qa/testlink/setup.sh                              # start TestLink → http://localhost:8090
python3 -I qa/testlink/scripts/load.py <name>     # requirements + suites + test cases + req links + plan
python3 -I qa/testlink/scripts/report.py <name>   # PDFs + XML → qa/project1/<name>/
```

To change test cases after loading: delete your top suite in TestLink (Test Specification → select it → delete),
edit the data file, run `load.py` again. Requirements are updated in place on reload.

Final group report (Rawa, after everyone pushed): `git pull`, then `load.py aland`, `load.py karoz`,
`load.py parwar`, then `report.py all` → `qa/project1/final/`.
